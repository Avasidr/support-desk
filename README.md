# Support Desk

A full-stack support ticket management platform built as a portfolio project.

The application is inspired by real-world support workflows and focuses on clean architecture, role-based authorization, ticket lifecycle management, notifications, reporting, and maintainability.

## Tech Stack

### Frontend

- Vue 3
- TypeScript
- Vite
- Tailwind CSS
- Pinia
- TanStack Query

### Backend

- PHP 8.4
- Laravel 13

### Database

- PostgreSQL

### Testing

- Vitest
- Playwright
- Pest / PHPUnit

### Infrastructure

- Docker
- Docker Compose
- GitHub Actions
